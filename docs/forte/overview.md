# Forte Framework Overview

Forte is a fullstack web framework for building applications that run on fn0. The backend compiles to `wasm32-wasip2` and is executed by the fn0 wasmtime runtime.

## Architecture

```
User Browser
     │  HTTP
     ▼
fn0 Worker (wasmtime)
     │  WASI:HTTP p3
     ▼
forte_sdk::serve::serve()   ← converts WASI HTTP ↔ http::Request/Response
     │
     ▼
dispatch() [generated by forte_codegen]
     │
     ├── /__self_invoke/{name}     → hooks
     ├── /__forte_action/{name}    → actions
     ├── /__forte_queue_task/execute → queue tasks
     ├── /__forte_admin/{name}     → admin tasks
     └── /{path}                   → pages / API routes
```

## Crate Structure

| Crate | Path | Role |
|-------|------|------|
| `forte-sdk` | `forte/sdk` | Runtime library: HTTP types, outbound client, cookies, OTel, utilities |
| `forte-macros` | `forte/macros` | Proc macros: `#[test]`, `#[forte_doc]` |
| `forte-json` | `forte/json` | Custom streaming JSON with camelCase ↔ snake_case conversion |
| `forte-codegen` | `forte/codegen` | Build-time code generator (call from `build.rs`) |
| `forte` CLI | `forte/cli` | Developer-facing build tool |
| `forte-rs-to-ts` | `forte/rs-to-ts` | Rust → TypeScript type generator |
| `forte-test-runner` | `forte/test-runner` | WASM test harness (used as `runner` in `.cargo/config.toml`) |

## Request Lifecycle

1. fn0 worker receives an HTTP request and invokes the WASM component.
2. `forte_sdk::serve::serve()` converts the WASI p3 request into a `http::Request<Vec<u8>>`.
3. OpenTelemetry span is created (`http.request`).
4. The generated `dispatch()` function:
   - Parses cookies from `Cookie` header into a `CookieJar`.
   - Classifies the path and calls the appropriate handler.
   - The handler returns `Result<Response<Body>, E>`.
   - Errors that downcast to `Redirect` produce a 302 response.
   - Other errors produce 500.
   - `Set-Cookie` headers are appended from the `CookieJar` delta.
5. The response is converted back to a WASI p3 response and returned.

## Source Directory Layout (Application)

```
src/
├── lib.rs              ← must contain the forte-managed marker block
├── route_generated.rs  ← auto-generated; do not edit
├── pages/              ← page routes (SSR)
│   └── index.rs
├── apis/               ← API routes (JSON responses)
│   └── users.rs
├── hooks/              ← server hooks (self-invocable)
│   └── my_hook.rs
├── actions/            ← server actions (called from frontend)
│   ├── mod.rs          ← auto-generated
│   └── create_post.rs
├── queue_task/         ← background tasks
│   ├── mod.rs          ← auto-generated
│   └── send_email.rs
└── admin/              ← admin-only tasks
    ├── mod.rs          ← auto-generated
    └── reindex.rs
```
