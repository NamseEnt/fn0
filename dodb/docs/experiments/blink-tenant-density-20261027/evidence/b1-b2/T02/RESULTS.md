# T02 Committed WAL Locations

Status: partial at source commit `6e3e370a16dd95fe2cae46d000393b829845f1f7`. The shared scanner records page image/delta frame offsets, payload offsets and lengths, payload CRC32C, header CRC32C, record LSN, page ID, batch and record identity, and commit frame/LSN. Locations remain staged with the pending batch and become visible only after commit sequence and rolling digest validation. `WalLog::scan_committed_page_locations` is read-only and returns only committed locations plus the committed-prefix length and incomplete tail size. The returned scan does not retain reconstructed page images. `WalLog::read_committed_page_payload` revalidates the selected frame, its exact source bytes, every sibling record in the transaction, and the commit digest before returning its payload. The scanner records each delta's base LSN/CRC and exact predecessor frame. `WalLog::reconstruct_page_location` reconstructs a two-delta chain from an image or from a supplied checkpoint base and validates every intermediate and final image checksum.

Checks: `cargo test -p dodb-storage --features blink-demand-paging wal::tests:: --lib` passed 32 tests. `rustfmt --check --edition 2024 --config skip_children=true dodb/crates/dodb-storage/src/wal.rs` and `cargo check -p dodb-storage --features blink-demand-paging --lib` passed.

This scan temporarily uses the existing page recovery map to validate deltas, then drops it before returning. T02 allows a temporary O(page count) foundation collector, but a bounded paged recovery consumer is not implemented. Live append-side location publication after successful WAL sync and the remaining T02 acceptance cases are not implemented. No runtime route consumes these locations yet.
